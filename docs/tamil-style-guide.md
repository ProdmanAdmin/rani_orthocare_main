# Tamil Style Guide for the Website
# இணையதளத் தமிழ் நடை வழிகாட்டி

Version 0.1, 2026-10-29. Agreed style: **A, simple written Tamil.** Every Tamil line on the website, in the prototype and in client documents follows this guide. The doctor approves the final medical wording; a native-speaker check (UAT) comes later.

## 1. The style in one line

Write Tamil the way a Tamil hospital pamphlet or a newspaper ad reads: **everyday sentences, and the English words people actually say, written in Tamil letters.** Not textbook or "pure" Tamil, and not spoken slang.

| | Example |
|---|---|
| Too formal (avoid) | எங்கே வலிக்கிறது என்று சொல்லுங்கள். நேரத்தைச் சொல்கிறோம். |
| **Style A (use)** | **எங்கே வலி இருக்கிறது என்று சொல்லுங்கள். டாக்டரைப் பார்க்க அப்பாயின்ட்மென்ட் நேரம் தருகிறோம்.** |
| Spoken (only for WhatsApp, Instagram and phone or camp scripts) | எங்க வலிக்குதுன்னு சொல்லுங்க. அப்பாயின்ட்மென்ட் நேரம் தர்றோம். |

## 2. Rules

1. **Meaning first.** If a Tamil reader could misread the line, say it fully, even if the English is shorter. Example: "a time" becomes "அப்பாயின்ட்மென்ட் நேரம்", not "நேரம்".
2. **Use the word patients use.** If people say the English word, write it in Tamil letters (அப்பாயின்ட்மென்ட், ஆபரேஷன், எக்ஸ்ரே). If they say a Tamil word, use that (வலி, மூட்டு, முதுகு).
3. **Standard verb endings,** not spoken ones: சொல்லுங்கள், not சொல்லுங்க; தருகிறோம், not தர்றோம்.
4. **Short sentences.** One idea per sentence. Break long English sentences into two Tamil ones.
5. **Explain a medical term once,** in brackets, the first time on a page: மூட்டு வீக்கம் (ஆர்த்ரைடிஸ்), பாத வளைவு (கிளப் ஃபுட்).
6. **Patient lines sound like a person talking:** "படி ஏறும்போது முட்டி வலிக்கிறது." Page text stays a little more careful.
7. **Questions work well as Tamil headlines** when that is how people ask: "ஆபரேஷன் மட்டும்தான் ஒரே வழியா?"
8. **Same medical rules as English:** no promises, no "cure", no "permanent", no "best". "வலி குறைய உதவுகிறோம்" (we help reduce pain), never "வலி போய்விடும்" (the pain will go).
9. **Fixed brand lines do not change:** உங்கள் இயக்கம், எங்கள் நோக்கம் and வாழ்க்கையே இயக்கம், இயக்கமே வாழ்க்கை.
10. **The doctor's official title** stays as on his card, in the credentials line only: எலும்புமுறிவு மற்றும் முடநீக்கியல் அறுவைசிகிச்சை நிபுணர். Everywhere else: "எலும்பு, மூட்டு சிறப்பு டாக்டர்" or "டாக்டர் மணிகண்டன்".
11. **Brand names and qualifications** stay in English letters: Google, Instagram, PRP, M.B.B.S. WhatsApp is written வாட்ஸ்அப் in buttons, because that is how people say it.
12. **Numbers, phone and times** in digits, exactly as in English: +91 94445 53070, காலை 9 முதல் இரவு 10 வரை.

## 3. Word list

| English | Use (Style A) | Avoid on the website |
|---|---|---|
| Appointment | அப்பாயின்ட்மென்ட் | முன்பதிவு, சந்திப்பு நேரம் |
| Book an appointment | அப்பாயின்ட்மென்ட் புக் செய்ய | முன்பதிவு செய்ய |
| Call (button) | போன் செய்ய | அழைக்கவும் |
| WhatsApp us | வாட்ஸ்அப் செய்ய | வாட்ஸ்அப் செய்யவும் |
| Doctor | டாக்டர் (மருத்துவர் is also fine in body text) | |
| Orthopaedic doctor | எலும்பு, மூட்டு சிறப்பு டாக்டர் | எலும்பியல் நிபுணர், முடநீக்கியல் நிபுணர் |
| Clinic | கிளினிக் | மையம் |
| Surgery, operation | ஆபரேஷன் | அறுவை சிகிச்சை (only in formal titles) |
| Non-surgical | ஆபரேஷன் இல்லாத சிகிச்சை | அறுவை சிகிச்சையற்ற |
| Knee | முட்டி (patient lines), முழங்கால் (page text) | |
| Knee replacement | முட்டி மாற்று ஆபரேஷன் / மூட்டு மாற்று ஆபரேஷன் | முழங்கால் மூட்டு மாற்று அறுவை சிகிச்சை |
| Joint pain | மூட்டு வலி | |
| Arthritis | மூட்டு வீக்கம் (ஆர்த்ரைடிஸ்) | |

| Fracture | எலும்பு முறிவு; patient lines: எலும்பு உடைதல் | |
| Pain relief | வலியைக் குறைப்பது, வலி குறைய | வலி நிவாரணம், வலி மேலாண்மை |
| Root cause | வலிக்கான உண்மையான காரணம் | மூல காரணம் |
| Move again | மீண்டும் நன்றாக நடக்க | இயல்பாக நடமாட, இயக்கத்தை மீட்டெடுத்தல் |
| Physiotherapy | பிசியோதெரபி | இயன்முறை மருத்துவம் |
